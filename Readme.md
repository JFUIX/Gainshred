## About the Project

GainShred is a gym website concept designed to give a fitness business a strong digital first impression. The experience uses a high-contrast black and neon-lime visual identity, bold display typography, clear membership plan sections, and prominent contact calls to action.

The page combines business information with a simple interactive BMI calculator to help visitors explore the gym concept and engage with the site.

## Problem It Addresses

A local gym website needs to communicate its identity, membership options, and next steps quickly. This concept brings those essentials into one responsive landing page, reducing friction between discovering the gym and making an enquiry.

## Key Features

- Responsive landing page for desktop and mobile
- High-contrast black, steel, and neon-lime design system
- Monthly, quarterly, and annual membership plan sections
- Interactive BMI calculator with metric and imperial input modes
- Before-and-after transformation presentation
- Location and WhatsApp contact calls to action
- Sticky navigation and responsive page sections
- Single-page implementation with no build step

## Technology Stack

- **HTML5** — page structure and content
- **CSS3** — responsive layouts, typography, and visual styling
- **Vanilla JavaScript** — BMI calculator and interface interactions
- **Google Fonts** — Anton and Barlow

## Run Locally

```bash
git clone https://github.com/JFUIX/Gainshred.git
cd Gainshred
```

Open `index.html` in a modern browser. No build tools or package installation are required.

## Project Status & Limitations

**Status:** Front-end demo / portfolio concept.

- Membership plans and prices are illustrative and should be replaced with verified business information.
- Online membership registration and payment are not implemented.
- The BMI calculator is a general informational feature, not a medical assessment.
- Contact details and location should be configured for the intended gym before public use.
